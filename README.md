# Ms to Mrs — mobile invitation

Мобильная HTML-страница по макету Canva:
https://www.canva.com/design/DAHamsBNfsk/y2gazG7QKhnuY1dKnW06dA/edit

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.
Для локального просмотра через HTTP:

```sh
python3 -m http.server 8080
```

Нажмите на сургучную печать, чтобы поднять карточку и прочитать приглашение.
Повторное нажатие возвращает карточку в конверт. Анимация учитывает
`prefers-reduced-motion`. Ширина страницы ограничена 480 px; на телефоне она
занимает доступную ширину. Без JavaScript карточка открыта.

- `index.html` — редактируемые тексты и структура.
- `styles.css` — мобильная композиция и анимация.
- `script.js` — открытие и закрытие карточки.
- `assets/` — оригинальные декоративные слои WebP и шрифты из PDF макета.

Шрифты извлечены из PDF как подмножества: они содержат символы исходного
приглашения. Для новых текстов могут понадобиться полные лицензированные
версии Eyesome Script и Cormorant Garamond. Опечатки в тексте макета сохранены.

Страница не отправляет RSVP: в макете нет контакта или адреса для ответа.
